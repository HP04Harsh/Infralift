# Images Directory

Place your uploaded images in this directory:

1. **infralift-logo.png** - Replace with your Infralift logo
2. **indian-flag.png** - Replace with your Indian flag PNG

The components are configured to look for these files:
- Sidebar: `/images/infralift-logo.png`
- Header: `/images/indian-flag.png`

Fallback mechanisms are in place if the images are not found.
